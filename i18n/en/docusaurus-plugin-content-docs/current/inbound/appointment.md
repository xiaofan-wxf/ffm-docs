# 入库预约与收货时间

## 收货时间

**正常收货：** 周一至周六，09:00–16:00 到货

**不收货日：**
- 周日
- 泰国法定节假日
- 大促活动前 1 天、后 2 天

## 预约方式

仓库采用系统预约方式接收货物。通过预约到货的客户优先收货上架；临时送货优先级最低。

**紧急入库**请提前联系商务，安排额外人力（另行报价）。

## 入库时效

| 情况 | 时效 |
|------|------|
| 正常商品（预约到货） | 收货后 48 小时内上架 |
| 新品（需做新品维护） | 不超过 72 小时 |
