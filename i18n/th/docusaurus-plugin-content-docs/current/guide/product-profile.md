# การสร้างโปรไฟล์สินค้า

โปรไฟล์สินค้าเป็นข้อมูลพื้นฐานของระบบ SCM การรับและจ่ายสินค้าทั้งหมดใช้บาร์โค้ดในโปรไฟล์เพื่อระบุตัวสินค้า

## การสร้างโปรไฟล์สินค้าทีละรายการ

**เส้นทาง:** สินค้า → โปรไฟล์สินค้า → คลิก **[ใหม่]** → กรอกบาร์โค้ดและชื่อสินค้า → คลิก **[บันทึก]**

**คำอธิบายฟิลด์:**

| ฟิลด์ | คำอธิบาย |
|-------|----------|
| บาร์โค้ดสินค้า | บาร์โค้ดจริงบนสินค้า ใช้สแกนเมื่อรับสินค้าเข้าคลัง |
| ชื่อสินค้า | รองรับภาษาจีน อังกฤษ และไทย |

:::caution
โปรไฟล์สินค้าที่สร้างใหม่จะมีสถานะ **ฉบับร่าง** ต้องคลิก **[เปิดใช้งาน]** ก่อนจึงจะใช้งานในการรับหรือจ่ายสินค้าได้
:::

**วิธีเปิดใช้งาน:** ไปที่รายการโปรไฟล์สินค้า → เลือกสินค้า → คลิก **[เปิดใช้งาน]**

---

## การนำเข้าจำนวนมาก

ใช้เมื่อมีสินค้าจำนวนมากที่ต้องเพิ่มในครั้งเดียว

**เส้นทาง:** สินค้า → โปรไฟล์สินค้า → เมนูแบบเลื่อนลงข้าง **[ใหม่]** → **[นำเข้าจำนวนมาก]** → ดาวน์โหลดแม่แบบ → กรอกข้อมูลสินค้า → บันทึก → คลิก **[เปิดไฟล์]** → อัปโหลด → คลิก **[นำเข้า]**

**ฟิลด์ในแม่แบบ:**

| คอลัมน์ | ฟิลด์ |
|---------|-------|
| Barcode | บาร์โค้ดสินค้า (ตรงกับ "บาร์โค้ดสินค้า" ใน SCM) |
| Commodity name | ชื่อสินค้า (ตรงกับ "ชื่อสินค้า" ใน SCM) |
| Specification | ขนาด/รุ่น |
| Shelf life item or not | สินค้ามีวันหมดอายุหรือไม่ |

**ขั้นตอน:**

1. คลิก **[ดาวน์โหลดแม่แบบ]** ในหน้านำเข้าจำนวนมาก
2. กรอกข้อมูลสินค้าตามรูปแบบแม่แบบและบันทึก
3. คลิก **[เปิดไฟล์]** เพื่ออัปโหลดไฟล์ที่กรอกเสร็จแล้ว
4. เมื่อระบบแสดง "จำนวนที่นำเข้าได้: X รายการ" ให้คลิก **[นำเข้า]**
5. หลังนำเข้าเสร็จ กลับไปที่รายการสินค้าแล้ว **[เปิดใช้งาน]** รายการใหม่ทั้งหมด

:::tip
หากแถวใดแสดงว่า "ไม่สามารถนำเข้าได้" มักเกิดจากบาร์โค้ดซ้ำหรือฟิลด์บังคับว่างเปล่า ให้แก้ไขแถวนั้นแล้วอัปโหลดใหม่
:::
