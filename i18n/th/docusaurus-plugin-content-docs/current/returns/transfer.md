# การโอนกรรมสิทธิ์สินค้า

ใช้สำหรับโอนสินค้าจากผู้ค้า A ไปยังผู้ค้า B

## การตั้งค่าเบื้องต้น (เมื่อบาร์โค้ดเหมือนกัน)

หากผู้ค้าทั้งสองฝ่ายมีบาร์โค้ดสินค้าเหมือนกัน สามารถเปิดการจับคู่อัตโนมัติได้ที่ SCM → ตั้งค่า → การตั้งค่านโยบาย → ติ๊กถูก ☑️ **การโอนกรรมสิทธิ์รองรับการจับคู่ด้วยคลิกเดียว** → บันทึก

เมื่อเปิดใช้งานแล้ว ระบบจะซิงค์ข้อมูลโปรไฟล์สินค้าทั้งหมดจากผู้ค้าที่โอนออกไปยังบัญชีผู้ค้าที่รับโอนโดยอัตโนมัติ

![การตั้งค่าจับคู่ด้วยคลิกเดียว](/img/img_027.png)

## ขั้นตอน

### ผู้ค้า A (โอนออก)

SCM → เอกสารคลังสินค้า → ใบโอนกรรมสิทธิ์ (โอนออก) → คลิก **[เพิ่มใหม่]** → กรอก **[รหัสผู้ค้าปลายทาง]** → เลือกสินค้า/จำนวน → บันทึก → อนุมัติ

![ใบโอนกรรมสิทธิ์ (โอนออก)](/img/img_028.png)

### ผู้ค้า B (รับโอน)

SCM → เอกสารคลังสินค้า → ใบโอนกรรมสิทธิ์ (รับโอน) → คลิก **[จับคู่สินค้า]** → **[จับคู่ด้วยคลิกเดียว]** → บันทึก → คลิก **[ยืนยัน]**

![ใบโอนกรรมสิทธิ์ (รับโอน)](/img/img_029.png)
![ยืนยันการจับคู่](/img/img_030.png)

> ผู้ค้าทั้งสองฝ่ายต้องยืนยันก่อน คลังจึงจะเห็นเอกสารและดำเนินการได้

### การดำเนินการของคลัง

เลือกเลขใบโอนกรรมสิทธิ์ → คลิก **[ดำเนินการทั้งหมด]** → สถานะจะเปลี่ยนเป็น "เสร็จสมบูรณ์" อัตโนมัติ

![คลังดำเนินการทั้งหมด](/img/img_032.png)
