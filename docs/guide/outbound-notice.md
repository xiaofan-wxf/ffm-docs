# 创建出库通知单

出库通知单（RW 单）用于非平台订单的手动出库，例如 B2B 出货、样品发送等场景。

## 操作流程

**操作路径：** SCM → 库存单据 → 出库通知单 → 点击【新增】

1. 填写出库类型和收件人信息
2. 在商品信息区选择要出库的商品并填写数量
3. 备注栏可填写特殊要求
4. 点击【保存】→ 点击【审核】

![出库通知单填写](/img/img_056.png)

![收件人信息填写](/img/img_057.png)

审核完成后，复制 **RW 单号**，发送到对应群组通知仓库操作。

:::caution 注意
出库通知单审核后即下发仓库，如需修改请提前取消审核或联系仓库操作人员。
:::
