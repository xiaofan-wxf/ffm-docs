# 入库预约与收货时间

## 收货时间

**正常收货：** 周一至周六，09:00–16:00 到货

**不收货日：**
- 周日
- 泰国法定节假日
- 大促活动前 1 天、后 2 天

## 预约方式

仓库采用系统预约方式接收货物。通过预约到货的客户优先收货上架；临时送货优先级最低。

**紧急入库**请提前联系商务，安排额外人力（另行报价）。

## 入库时效

入库时效标准（48h / 新品 72h）见 [入库时效](../operations/inbound-sla)。
