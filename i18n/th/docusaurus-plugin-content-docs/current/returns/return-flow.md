# ขั้นตอนการจัดการสินค้าคืน

## สถานการณ์ที่ 1: สินค้าคืนจากคลังนอกพื้นที่ (พัสดุถึงคลังก่อนที่ผู้ค้าสร้างใบสินค้าคืน)

1. พัสดุคืนถึงคลังและถูกบันทึกในระบบ
2. ผู้ค้าเข้าสู่ระบบ SCM → ขาย → **ทะเบียนสินค้าคืน** → ค้นหาด้วยเลขติดตามพัสดุ → คลิก **[อ้างสิทธิ์]**
3. หลังจากคลังได้รับการแจ้งเตือน พัสดุจะถูกนำขึ้นชั้นกลับเข้าคลัง

## สถานการณ์ที่ 2: สินค้าคืนจากคลังนอกพื้นที่ (ผู้ค้าสร้างใบสินค้าคืนแล้ว พัสดุมาถึงทีหลัง)

1. ผู้ค้าเข้าสู่ระบบ SCM และสร้างใบสินค้าคืนล่วงหน้า สามารถเพิ่มบันทึกการจัดการพิเศษในเอกสารได้
2. เมื่อพัสดุถึงคลัง เจ้าหน้าที่จะจับคู่กับใบสินค้าคืนตามเลขติดตามพัสดุและรวมสถานะ
3. คลังนำสินค้าขึ้นชั้นกลับเข้าคลัง

## สถานการณ์ที่ 3: สินค้าคืนจากคลังในพื้นที่

ขั้นตอนเหมือนสถานการณ์ที่ 2 ผู้ค้าไม่ต้องสร้างใบสินค้าคืนด้วยตนเอง ระบบจะสร้างให้อัตโนมัติ

## การจัดการส่งสินค้าผิด / ส่งขาด

**ส่งสินค้าผิด:**
1. ผู้ค้าให้ข้อมูลติดต่อผู้ซื้อ
2. คลังติดต่อผู้ซื้อเพื่อขอรับสินค้าที่ส่งผิดคืน
3. หลังผู้ค้าอนุมัติการส่งใหม่ คลังติดต่อผู้ซื้อเพื่อส่งสินค้าที่ถูกต้องและแก้ไขปัญหา
4. สินค้าที่ได้รับคืนจะถูกนำขึ้นชั้นกลับเข้าคลัง

**ส่งขาด:**
1. ผู้ค้าให้ข้อมูลติดต่อผู้ซื้อ และผู้ค้าอนุมัติการส่งใหม่
2. คลังติดต่อผู้ซื้อเพื่อส่งสินค้าที่ขาดและแก้ไขปัญหา
