# 订单预处理：商品异常处理

![SCM首页，异常发货单可快速定位](/img/img_087.png)

订单进入 SCM 后，系统自动按以下顺序匹配商品：

1. **优先**：按商品档案条形码自动匹配
2. **其次**：按商品映射关系中维护的条形码匹配

当平台订单进入异常、商品异常、无法匹配商品时，有以下两个操作入口。

---

## 入口一：订单预处理页面手动映射

**操作路径：** 销售 → 订单预处理

![订单预处理页面](/img/img_084.png)

1. 在「外部单号」栏搜索平台订单号，找到需要处理的异常订单

![商品异常订单详情，条形码为空需维护](/img/img_085.png)

2. 点击「条形码」列下的**图案图标**
3. 在弹出窗口中，维护对应的商品档案条形码
4. 点击【自动映射异常商品】

![自动映射异常商品按钮](/img/img_086.png)

5. 点击【生成发货单】

---

## 入口二：直接在商品映射关系维护

如果是系统性的 SKU 不匹配问题（多个订单都受影响），建议在商品映射关系中直接维护：

**操作路径：** 商品 → 商品映射关系

1. 找到对应的平台 SKU 条目
2. 在「条形码」处填入 SCM 商品档案的正确条形码
3. 点击【库存更新】

维护完成后，后续相同 SKU 的订单将自动正确匹配，无需逐单处理。

---

## 常见商品异常原因

| 原因 | 解决方式 |
|------|---------|
| 平台商品链接未维护 Seller SKU | 在平台后台商品管理中添加 Seller SKU |
| 平台 SKU 与 SCM 条形码不一致 | 在商品映射关系中手动维护映射 |
| 商品档案条形码有重复 | 检查并修正 SCM 商品档案中的重复条形码 |
| 商品档案未启用 | 在商品档案中将该商品状态改为【启用】 |

更多订单同步问题请参考 [订单抓取与同步问题](../orders/sync-issues)。
