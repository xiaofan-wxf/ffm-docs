# การเติมเงินล่วงหน้า

## ภาพรวม

ผู้ค้าเติมเงินเข้าบัญชีล่วงหน้า ระบบจะหักเงินจากยอดล่วงหน้าทุกวันตามรายการค่าใช้จ่าย ระบบจะแจ้งเตือนเมื่อยอดเงินเหลือน้อย และเมื่อยอดเป็น 0 จะไม่สามารถอนุมัติและส่งเอกสารให้คลังได้

## ขั้นตอนการเติมเงิน

1. SCM → การชำระเงิน → ยอดเงินของฉัน → คลิก **[เติมเงิน]**
2. กรอกจำนวนเงินและข้อมูลการโอน จากนั้นอัปโหลดหลักฐานการโอนเงิน
3. ส่งและรอให้ฝ่ายการเงินยืนยันการรับเงิน
4. เมื่อฝ่ายการเงินยืนยันแล้ว ยอดเงินใน SCM จะอัปเดตอัตโนมัติ
