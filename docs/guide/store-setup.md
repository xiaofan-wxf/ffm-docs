# 店铺档案创建与授权

## 添加店铺

**操作路径：** SCM → 设置 → 店铺档案 → 点击【新增】

![店铺档案列表，点击新增](/img/11_店铺档案列表.jpg)

1. 填写店铺名称
2. 选择销售平台（TikTok / Shopee / Lazada / 其他）
3. 选择国家
4. 点击【保存】→ 点击【启用】

![新增店铺表单](/img/11_新增店铺档案.jpg)

:::caution 注意
新添加的店铺默认为存盘状态，需点击【启用】才可使用。店铺保存后，再进行平台授权，授权完成后回来配置店铺接口信息。
:::

---

## 店铺授权

### TikTok 授权

**操作路径：** SCM → 设置 → 店铺档案 → 找到对应 TikTok 店铺 → 点击【去授权】

TikTok 跨境 3PF 和本土店铺使用不同的授权入口：

| 店铺类型 | 授权入口 |
|---------|---------|
| 跨境 3PF 店铺 | 选择 "Plus seller" |
| 本土店铺 | 选择 "Thailand" 直接账号密码登录 |

![TikTok授权入口选择](/img/12_TikTok授权入口.jpg)

:::caution TK 跨境店注意
TK 跨境店：主账号授权后，需选择要授权的具体子店铺，一对一授权。一品多仓需在创建档案时勾选（保存后**不可取消**）。
:::

![TikTok一品多仓说明](/img/12_TikTok一品多仓说明.jpg)

---

### Shopee 授权

**操作路径：** SCM → 设置 → 店铺档案 → 找到对应 Shopee 店铺 → 点击【去授权】

| 店铺类型 | 登录方式 |
|---------|---------|
| 本土店铺 | 按国家选择后，输入账号密码登录 |
| 3PF 跨境店铺 | 点击 "Switch to Sub Account"，用主账号登录 |

![Shopee授权本土店](/img/13_Shopee授权_本土店.jpg)

![Shopee授权3PF](/img/13_Shopee授权_3PF.jpg)

### Lazada 授权

Lazada 需先在服务市场订购 Flash WMS，再回 SCM 完成授权。

:::caution
Lazada 已更新授权流程，请按最新步骤操作。
:::

1. 登录 Lazada 卖家后台 → 点击【服务市场】

![Lazada服务市场搜索](/img/14_Lazada服务市场搜索.jpg)

2. 搜索「Flash」找到 Flash WMS → 点击应用 → 选择【仅授权】→ 周期【半年】→ 点击【授权使用】

![Lazada选择授权方式](/img/14_Lazada选择授权方式.jpg)

3. 勾选「已同意并签署」→ 点击【确认】→ 提示「订购成功」

![Lazada确认订购](/img/15_Lazada确认订购.jpg)

![Lazada订购成功](/img/15_Lazada订购成功.jpg)

4. 在订购成功页点击「授权服务」按钮
5. 回 SCM → 设置 → 店铺档案 → 找到 Lazada 店铺 → 点击【点击授权】
6. 在 Lazada Open Platform 授权页选择国家 → 输入邮箱密码 → Submit

![Lazada Open Platform授权](/img/16_Lazada_OpenPlatform授权.jpg)

![Lazada授权成功](/img/16_Lazada授权成功.jpg)

## 绑定 Flash 仓库

授权完成后，需在 SCM 中将平台仓库与 Flash 仓绑定，系统才能正确拉取该仓的订单。

**操作路径：** 设置 → 店铺档案 → 找到已授权店铺 → 点击【修改】

1. 点击【获取平台仓库】，拉取平台仓库列表
2. 在列表中点击右侧【编辑】

![平台仓库设置](/img/17_平台仓库设置.jpg)

3. 将「是否获取该仓订单」设为 **是**
4. 在「分配到具体 FFM 仓」勾选对应的 Flash 仓库
5. 点击【保存】

![仓库绑定配置](/img/17_仓库绑定配置.jpg)

:::caution 注意
此步骤完成后，系统才会从对应 Flash 仓拉取该平台的订单。如果订单未进 SCM，请先检查此配置是否正确设置。
:::

## 开启自动审单

自动审单开启后，所有进入 SCM 的订单将自动审核下发仓库，无需人工逐单操作。

**操作路径：** SCM → 设置 → 策略设置 → 审单设置 → 点击【修改】

1. 勾选 ☑️ **开启智能审单**
2. 点击【保存】

:::info
默认开启后适用于所有店铺、所有订单来源。也可以针对个别店铺单独勾选"开启智能审单"。
:::

## 自动同步库存设置

库存同步需要先完成商品映射（见[商品映射指南](./product-mapping)），再开启自动同步。

### 按店铺批量修改

**操作路径：** 商品 → 商品映射关系 → 【按店铺批量修改】

![商品映射关系列表](/img/18_商品映射关系列表.jpg)

1. 选择需要开启自动同步库存的店铺
2. 勾选「启用库存更新」：**是**
3. 勾选「库存更新百分比」：默认 **100%**（代表仓库所有库存都同步到平台）
   - 如果多店铺共享同一仓库库存，可按实际分配比例填写
4. 保存 → 系统定时自动同步

![按店铺批量修改](/img/18_按店铺批量修改.jpg)

### 按商品批量修改库存信息

**操作路径：** 商品 → 商品映射关系 → 选择商品 → 点击【批量修改库存信息】

![勾选商品批量修改](/img/19_勾选商品批量修改.jpg)

同样设置「启用库存更新：是」和「库存更新百分比」后保存。

![批量修改库存信息](/img/19_批量修改库存信息.jpg)
