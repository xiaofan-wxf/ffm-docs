# การจับคู่สินค้าและการซิงค์สต็อก

การจับคู่สินค้าเชื่อมโยง **Seller SKU ของแพลตฟอร์ม** กับ **บาร์โค้ดในโปรไฟล์สินค้า SCM** ทำให้คำสั่งซื้อจากแพลตฟอร์มจับคู่สินค้าในระบบได้อัตโนมัติ และซิงค์สต็อกคลังกลับไปยังแพลตฟอร์ม

## การตั้งค่า Product Mapping

**เส้นทาง:** SCM → สินค้า → Product Mapping → คลิกเมนูแบบเลื่อนลงข้าง **[ใหม่]** → **[ซิงค์สินค้า]**

1. เลือกร้านค้าที่ต้องการจับคู่
2. ช่วงเวลา: เลือก **ทั้งหมด**
3. คลิก **[ดึงสินค้า]** หรือ **[ซิงค์สต็อก]**
4. SKU ของแพลตฟอร์มจะถูกดึงเข้า SCM และสต็อกคลังปัจจุบันจะซิงค์ไปยังแพลตฟอร์ม

:::info
หากบาร์โค้ดในโปรไฟล์สินค้าตรงกับ SKU ของแพลตฟอร์มพอดี ระบบจะ **จับคู่อัตโนมัติ** โดยไม่ต้องดำเนินการด้วยตนเอง
:::

### เมื่อบาร์โค้ดและ SKU ของแพลตฟอร์มไม่ตรงกัน

ต้องจับคู่ด้วยตนเอง:

1. หารายการที่ยังไม่ได้จับคู่ในรายการ Product Mapping
2. คลิกรายการเพื่อเปิดรายละเอียด
3. กรอกบาร์โค้ดสินค้า SCM ในช่อง "บาร์โค้ด"
4. คลิก **[อัปเดตสต็อก]** เพื่อซิงค์สต็อกไปยังแพลตฟอร์ม

## การจับคู่สินค้าชุด (Bundle)

ใช้เมื่อแพลตฟอร์มลิสต์ SKU แบบชุด (ขายรวมหลายชิ้น)

### ขั้นตอน

**ขั้นตอนที่ 1: สร้างโปรไฟล์ Bundle ใน SCM**

เส้นทาง: สินค้า → Bundle สินค้า → คลิก **[ใหม่]**

![รายการโปรไฟล์ชุดสินค้า](/img/20_套装档案列表.jpg)

1. กรอกชื่อชุดสินค้า
2. เพิ่มสินค้าและจำนวนในชุด (เลือกจากโปรไฟล์สินค้าที่มีอยู่)
3. บันทึก → คลิก **[เปิดใช้งาน]**

![สร้างโปรไฟล์ชุดสินค้า](/img/20_套装档案创建.jpg)

**ขั้นตอนที่ 2: ซิงค์สินค้า Bundle ของแพลตฟอร์ม**

เหมือนกับการจับคู่สินค้าปกติ: Product Mapping → เมนูใหม่ → ซิงค์สินค้า → เลือกร้านค้า → ดึงสินค้า

**ขั้นตอนที่ 3: ตั้งค่าการจับคู่ Bundle**

1. หา SKU Bundle ของแพลตฟอร์มในรายการ Product Mapping
2. คัดลอกบาร์โค้ด Bundle จาก SCM
3. วางบาร์โค้ด Bundle ในช่อง "บาร์โค้ด" ของรายการนั้น
4. คลิก **[อัปเดตสต็อก]** เพื่อซิงค์สต็อก Bundle ไปยังแพลตฟอร์ม

![การแมปชุดสินค้า](/img/21_套装映射关系.jpg)

![อัปเดตสินค้าคงคลังชุดสินค้า](/img/21_套装库存更新.jpg)

## การซิงค์สต็อกด้วยตนเอง

### ซิงค์ทีละ SKU

**เส้นทาง:** สินค้า → Product Mapping → หาสินค้า → คลิก **[อัปเดตสต็อก]** ทางขวา

![อัปเดตสินค้าคงคลัง SKU เดียว](/img/22_单SKU库存更新.jpg)

หลังคลิก ตรวจสอบ **[บันทึกการอัปเดตสต็อก]** เพื่อดูรายละเอียดความสำเร็จหรือความล้มเหลว

### ซิงค์จำนวนมากตามร้านค้า

**เส้นทาง:** สินค้า → Product Mapping → เมนูแบบเลื่อนลงข้างใหม่ → **[ซิงค์สินค้า]**

![การซิงค์เป็นกลุ่มตามร้านค้า](/img/22_按店铺批量同步.jpg)

1. เลือกร้านค้า
2. ช่วงเวลา: เลือก **ทั้งหมด**
3. คลิก **[ซิงค์สต็อก]** → ซิงค์สต็อกคลังปัจจุบันไปยังแพลตฟอร์ม

หลังซิงค์เสร็จ ตรวจสอบ **Product Mapping → บันทึกการอัปเดตสต็อก** เพื่อดูผลลัพธ์
