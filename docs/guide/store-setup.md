# 店铺档案创建与授权

## 添加店铺

**操作路径：** SCM → 设置 → 店铺档案 → 点击【新增】

1. 填写店铺名称
2. 选择销售平台（TikTok / Shopee / Lazada / 其他）
3. 选择国家
4. 填写店铺描述（可选）
5. 寄件人信息：选择"使用仓库的寄件地址"
6. 点击【保存】→ 点击【启用】

:::caution 注意
新添加的店铺默认为存盘状态，需点击【启用】才可使用。店铺保存后，再进行平台授权，授权完成后回来配置店铺接口信息。
:::

---

## 店铺授权

### TikTok 授权

**操作路径：** SCM → 设置 → 店铺档案 → 找到对应 TikTok 店铺 → 点击【去授权】

TikTok 跨境 3PF 和本土店铺使用不同的授权入口：

| 店铺类型 | 授权入口 |
|---------|---------|
| 跨境 3PF 店铺 | 选择 "3P Seller"（选择 Thailand 等对应国家子账号授权入口） |
| 本土店铺 | 选择 "Thailand" 直接账号密码登录 |

:::caution TK 跨境店注意
TK 跨境店：主账号授权后，需选择要授权的具体子店铺，一对一授权。
:::

#### TikTok 一品多仓授权

TK 一品多仓店铺需在 SCM 创建/修改店铺档案时勾选"开通一品多仓"：

1. 确认在 TikTok 平台后台已开通一品多仓白名单
2. SCM 店铺档案 → 修改 → 勾选 ☑️ **开通一品多仓**
3. 保存后无法取消，再进行授权

**如何区分 TikTok 是否一品多仓：**

在 TikTok 平台创建全球商品时，进入【仓库和库存】模块：
- **是一品多仓**：可以根据自己的仓库，将全球商品放入不同仓库，按仓库输入库存
- **非一品多仓**：发布国家页面只能选择一个仓库

---

### Shopee 授权

**操作路径：** SCM → 设置 → 店铺档案 → 找到对应 Shopee 店铺 → 点击【去授权】

在 Shopee 授权页面：

| 店铺类型 | 登录方式 |
|---------|---------|
| 本土店铺 | 按国家选择后，输入账号密码登录 |
| 3PF 跨境店铺 | 点击 "Switch to Sub Account"，用主账号登录 |

---

### Lazada 授权

Lazada 授权分为两步：**先在 Lazada 服务市场订购 Flash WMS，再在 SCM 点击授权**。

#### 第一步：Lazada 服务市场订购

1. 登录 Lazada 卖家后台 → 点击**服务市场**
2. 搜索 `Flash` → 找到 **FLASH WMS** 应用
3. 选择【仅授权】→ 周期选**半年** → 点击【授权使用】
4. 勾选「已同意并签署」→ 点击【确认】→ 提示"订购成功"

#### 第二步：SCM 系统授权

5. 返回 SCM → 设置 → 店铺档案 → 选择对应店铺 → 点击【去授权】
6. 选择国家 → 输入店铺登录邮箱和密码 → 点击「Submit」
7. 页面显示 "Authorization success" 表示授权成功

授权成功后，回到 SCM 店铺档案，该店铺的授权状态更新为【已授权】，并显示授权有效期。

:::tip
Lazada 授权有有效期，到期前必须重新授权，否则订单将无法同步。
:::

## 授权后配置

### 1. 在平台后台维护发货地址

授权成功后，需在对应平台店铺后台将**发货地址**更新为 Flash 仓库地址：
- TikTok：商家资料 → 仓库管理 → 选择 Flash Fulfillment 仓库
- Lazada：Seller Center → 物流 → 发货地址 → 填入对应 Flash 仓库地址

### 2. SCM 平台仓库设置

**操作路径：** SCM → 设置 → 店铺档案 → 找到已授权店铺 → 点击【修改】

1. 点击【获取平台仓库】，拉取平台的仓库列表
2. 找到 Flash 仓库，点击右侧【编辑】
3. 设置"是否获取该仓订单"：**是**
4. 勾选对应 FFM 仓 → 保存

---

## 开启自动审单

自动审单开启后，所有进入 SCM 的订单将自动审核下发仓库，无需人工逐单操作。

**操作路径：** SCM → 设置 → 策略设置 → 审单设置 → 点击【修改】

1. 勾选 ☑️ **开启智能审单**
2. 点击【保存】

:::info
默认开启后适用于所有店铺、所有订单来源。也可以针对个别店铺单独勾选"开启智能审单"。
:::

## 自动同步库存设置

库存同步需要先完成商品映射（见[商品映射指南](./product-mapping)），再开启自动同步。

### 按店铺批量修改

**操作路径：** 商品 → 商品映射关系 → 【按店铺批量修改】

1. 选择需要开启自动同步库存的店铺
2. 勾选「启用库存更新」：**是**
3. 勾选「库存更新百分比」：默认 **100%**（代表仓库所有库存都同步到平台）
   - 如果多店铺共享同一仓库库存，可按实际分配比例填写
4. 保存 → 系统定时自动同步

### 按商品批量修改库存信息

**操作路径：** 商品 → 商品映射关系 → 选择商品 → 点击【批量修改库存信息】

同样设置「启用库存更新：是」和「库存更新百分比」后保存。
