# ปัญหาบิลที่พบบ่อย

## ค่าจัดเก็บสินค้าผิดปกติ

**สาเหตุที่เป็นไปได้:**
1. ข้อมูลขนาดสินค้าในโปรไฟล์สินค้าไม่ถูกต้อง ทำให้การคำนวณค่าใช้จ่ายไม่แม่นยำ
2. การย้ายสินค้าทำให้พื้นที่จัดเก็บเพิ่มขึ้น

**วิธีแก้ไข:** ติดต่อเจ้าหน้าที่ปฏิบัติการเพื่อตรวจสอบข้อมูลขนาดสินค้าในโปรไฟล์ หรือยืนยันบันทึกการย้ายสินค้า

## ค่าวัสดุบรรจุภัณฑ์ผิดปกติ

**สาเหตุที่เป็นไปได้:** สแกนซ้ำ, สแกนผิด หรือสแกนไม่ครบ

**วิธีแก้ไข:** ระบุเลขใบสั่งจัดส่งและติดต่อเจ้าหน้าที่ปฏิบัติการเพื่อตรวจสอบบันทึกการสแกน

## รายการค่าใช้จ่ายหายเนื่องจากใบเช่าหมดอายุ

โปรดต่ออายุใบเช่าก่อนหมดอายุ มิฉะนั้นระบบจะหยุดสร้างรายการค่าใช้จ่ายที่เกี่ยวข้อง

## บริการเสริม (Value-added Services)

บริการต่อไปนี้ต้องยื่นคำขอล่วงหน้า และคิดค่าใช้จ่ายตามอัตราในสัญญา:
- **บริการรถ:** SCM → เอกสารคลังสินค้า → ใบขอบริการ → เพิ่มใหม่ → กรอกข้อมูล → บันทึก → อนุมัติ จากนั้นคัดลอกเลข VO แจ้งฝ่ายธุรกิจ/คลัง
- **การทำงานล่วงเวลาคลัง:** ติดต่อฝ่ายธุรกิจเพื่อขอใบเสนอราคา

## สามารถนำวัสดุบรรจุภัณฑ์ของตัวเองมาใช้ได้ไหม?

**ไม่ได้** คลังมีสายการแพ็กหลายสาย วัสดุที่ผู้ค้านำมาเองจัดการได้ยาก

หากมีข้อกังวลเรื่องราคาวัสดุ สามารถสอบถามเรื่องการเปลี่ยนเป็นถุงพลาสติกสีเทาไม่มีลาย (ราคาถูกกว่า)

## คำถามที่พบบ่อยอื่น ๆ

| คำถาม | คำตอบ |
|-------|-------|
| เวลาขนส่งทางเรือ/ทางบก | ขึ้นอยู่กับเส้นทาง กรุณาติดต่อฝ่ายธุรกิจ |
| ค่าขนส่งทางเรือ/ทางบกขั้นต่ำ | ขั้นต่ำ 1 CBM ไม่มีข้อจำกัดอื่น |
| ภาษีขนส่งทางเรือ/ทางบก | อัตราภาษี 0% |
| หน่วยคิดค่าบริการนำขึ้นชั้น | คิดต่อชิ้น กล่องมาตรฐานสามารถมีกล่องซ่อนได้ |
| ขนส่ง Last-mile | ออร์เดอร์แพลตฟอร์มใช้ขนส่งที่แพลตฟอร์มกำหนด ออร์เดอร์นอกแพลตฟอร์มใช้ขนส่งที่คลังกำหนด (ปัจจุบันรองรับเฉพาะ Flash Express) |
| การชดเชยสินค้าสูญหาย First-mile | ตามเงื่อนไขสัญญาขนส่ง First-mile มาตรฐานปัจจุบันไม่เกิน 200 RMB ต่อชิ้น |
