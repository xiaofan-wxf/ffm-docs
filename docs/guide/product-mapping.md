# 商品映射与库存同步

商品映射的作用：将**平台 Seller SKU**与 SCM **商品档案条形码**关联，使平台订单进入 SCM 时能自动匹配到正确商品，并将仓库库存同步回平台。

## 同步平台 SKU

**操作路径：** SCM → 商品 → 商品映射关系 → 点击【新增】右侧下拉键 → 点击【同步商品】

1. 选择需要映射的店铺
2. 时间范围选**全部**
3. 点击【获取商品】或【同步库存】
4. 平台商品 SKU 链接会同步进 SCM，并同步现有仓库可用库存到平台

:::info
如果商品档案/商品套装的条形码与平台 SKU 完全一致，系统会**自动匹配**，无需手动维护映射关系。
:::

### 条形码与平台 SKU 不一致时

需要手动维护映射：

1. 在商品映射关系列表找到未匹配的条目
2. 点击条目进入详情
3. 在「条形码」处输入 SCM 商品档案的条形码
4. 点击【库存更新】，同步库存到平台

## 套装商品映射

适用于平台上架了套装 SKU（多个单品组合销售）的场景。

**第一步：在 SCM 创建商品套装档案**

操作路径：商品 → 商品套装 → 点击【新增】

![套装档案列表](/img/20_套装档案列表.jpg)

1. 填写套装名称
2. 添加套装包含的单品及数量（从已有商品档案中选择）
3. 保存 → 点击【启用】

![套装档案创建](/img/20_套装档案创建.jpg)

**第二步：同步平台套装商品**

与普通商品映射相同：商品映射关系 → 新增下拉 → 同步商品 → 选择店铺 → 获取商品

**第三步：配置套装映射**

1. 在商品映射关系列表找到平台的套装 SKU 条目
2. 复制 SCM 套装档案的条形码
3. 在该条目的「条形码」处粘贴套装条形码
4. 点击【库存更新】，同步套装库存到平台

![套装映射关系](/img/21_套装映射关系.jpg)

![套装库存更新](/img/21_套装库存更新.jpg)

## 手动同步库存

### 单个 SKU 同步

**操作路径：** 商品 → 商品映射关系 → 找到要同步的商品 → 点击右侧【库存更新】

![单SKU库存更新](/img/22_单SKU库存更新.jpg)

点击后可在【库存更新日志】中查看同步成功或失败的原因日志。

### 按店铺维度批量同步

**操作路径：** 商品 → 商品映射关系 → 新增右侧下拉键 → 点击【同步商品】

![按店铺批量同步](/img/22_按店铺批量同步.jpg)

1. 选择店铺
2. 时间范围选**全部**
3. 点击【同步库存】→ 同步现有仓库可用库存到平台后台

点击同步完成后，在【商品映射关系】→ 库存更新日志中查看同步成功/失败原因的日志。
