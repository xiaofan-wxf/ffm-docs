# การสร้างใบแจ้งจ่ายสินค้า

ใบแจ้งจ่ายสินค้า (คำสั่ง RW) ใช้สำหรับการจ่ายสินค้าด้วยตนเองที่ไม่ใช่คำสั่งซื้อแพลตฟอร์ม เช่น การส่ง B2B การส่งตัวอย่าง เป็นต้น

## ขั้นตอน

**เส้นทาง:** SCM → เอกสารสินค้าคงคลัง → ใบแจ้งจ่ายสินค้า → คลิก **[ใหม่]**

1. เลือกประเภทการจ่ายสินค้าและกรอกข้อมูลผู้รับ
2. เลือกสินค้าที่ต้องการส่งและกรอกจำนวน
3. กรอกคำแนะนำพิเศษในช่องบันทึก
4. คลิก **[บันทึก]** → คลิก **[อนุมัติ]**

หลังอนุมัติ คัดลอก **หมายเลขคำสั่ง RW** และส่งไปยังกลุ่มที่เกี่ยวข้องเพื่อแจ้งคลังสินค้า

:::caution
เมื่ออนุมัติแล้ว ใบแจ้งจ่ายสินค้าจะถูกส่งไปยังคลัง หากต้องการแก้ไข ให้ยกเลิกการอนุมัติก่อนหรือติดต่อเจ้าหน้าที่คลังสินค้า
:::
