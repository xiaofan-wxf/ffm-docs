# 创建入库通知单

入库通知单（AN 单）是货物进入仓库的凭证，仓库凭 AN 单收货和上架。

## 基本操作流程

**操作路径：** SCM → 库存单据 → 入库通知单 → 点击【新增】

### 第一步：填写入库单

1. 进入新增入库通知单界面
2. 选择入库类型
3. 在商品信息区点击【选择】，添加要入库的商品
4. 填写每个商品的数量
5. 备注栏可填写头程信息（如运单号等）
6. 点击【保存】

:::caution 重要
刚保存的入库通知单状态为**待审核**。**已审核下发仓库的入库单，无法再创建箱单信息生产箱单标签**，请务必先完成箱单管理，再审核。
:::

### 第二步：创建箱单（分箱信息）

箱单用于头程贴在商品外箱上，到货时仓库便于识别货主和入库单信息。

**操作路径：** 库存单据 → 入库通知单 → 点击【未审核】状态的 AN 单号 → 进入入库单详情 → 点击【箱单管理】

有两种方式维护分箱信息：

#### 方式 A：直接修改（少量商品）

点击【修改】→ 添加商品和分箱数量 → 点击【保存】

#### 方式 B：批量导入（多种商品/多箱）

1. 点击【批量导入】→ 点击【模板下载】，下载箱单模板
2. 按模板格式填写：

| 列名 | 说明 |
|------|------|
| Quantity Per Box（每箱数量） | 每箱里面商品的数量 |
| Number Of Boxes（箱数） | 共几箱 |
| Barcode（条形码） | 入库商品实际条形码 |

3. 填写完成保存后，点击【打开文件】上传
4. 显示"可导入数量：X 条"后点击【导入】
5. 导入成功后点击【箱单下载】，生成含箱单信息的 PDF 文件

### 第三步：打印箱单并审核

1. 下载箱单 PDF 后，连接打印机打印箱单
2. 将箱单贴在对应的每箱商品外箱上
3. 回到入库通知单列表，勾选该 AN 单 → 点击【审核】→ 下发仓库

**箱单内容说明：**  
系统自动生成含货主信息、入库单号、箱号/总箱数、商品条形码和数量的标签。

## 混箱商品操作

适用于一个箱子内装有多个 SKU 的情况。

**操作路径：** 库存单据 → 入库通知单 → 点击未审核的 AN 单号 → 点击【修改】

1. 在修改页面点击【添加商品】，选择要入库的商品
2. 点击【混箱商品】，输入商品混箱数量
3. 填写每行对应的每箱数量和箱数
4. 点击【保存】
5. 点击【箱单下载】，导出含混箱信息的 PDF 箱单
6. 打印后贴在对应箱子上

**混箱箱单示例：**
- 箱 1/2：商品 A（每箱5件）+ 商品 B（每箱10件）
- 箱 2/2：商品 A（每箱5件）+ 商品 B（每箱10件）

:::info
混箱时，同一箱内的每个 SKU 都会打印在同一张箱单上，方便仓库清点核对。
:::
