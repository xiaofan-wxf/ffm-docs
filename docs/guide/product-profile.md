# 商品档案创建

商品档案是 SCM 系统的基础数据，入库和出库均依赖档案中的条形码进行识别。

## 单个商品档案创建

**操作路径：** 商品 → 商品档案 → 点击【新增】→ 维护商品条形码/商品名称 → 点击【保存】

**填写说明：**

| 字段 | 说明 |
|------|------|
| 商品条形码 | 商品本身条码，入库时按照维护的条码扫码入库 |
| 商品名称 | 支持中文、英文、泰文 |

:::caution 注意
新创建的商品档案默认为**存盘状态**，需要点击【启用】后才可以在入库单/发货单中使用。
:::

**启用步骤：** 商品档案列表 → 选中商品 → 点击【启用】

---

## 商品档案批量导入

适用于商品数量较多时，批量创建商品档案。

**操作路径：**

商品 → 商品档案 → 点击【新增】右侧下拉键 → 点击【批量导入】→ 下载模板 → 填写模板商品信息 → 保存 → 点击【打开文件】→ 上传模板 → 点击【导入】

**模板字段说明：**

| 列名 | 对应字段 |
|------|---------|
| Barcode | 商品条形码（对应 SCM 商品档案里"商品条形码"） |
| Commodity name | 商品名称（对应 SCM 商品档案里"商品名称"） |
| Specification | 规格 |
| Shelf life item or not | 是否有效期商品 |

**导入步骤：**

1. 在批量导入页面点击【模板下载】，下载标准 Excel 模板
2. 在模板中按格式填写商品信息并保存
3. 点击【打开文件】上传填好的模板文件
4. 系统显示"可导入数量：X 条"后，点击【导入】
5. 导入成功后，回到商品档案列表批量【启用】

:::tip
如果模板中某行显示"不可导入"，通常是因为条形码重复或必填字段为空，检查对应行数据后重新上传。
:::
