# มาตรฐานใบรายการสินค้าและเกณฑ์การปฏิเสธรับสินค้า

## ข้อกำหนดใบรายการสินค้า (Packing List)

- ทุกกล่องต้องติดใบรายการสินค้าตามมาตรฐานที่กำหนด
- ไม่รับสินค้าแบบผสมกล่อง (Mixed SKU โดยไม่มีการแยกชัดเจน)
- หากในกล่องเดียวมีหลาย SKU ต้องแยกให้ชัดเจนด้วยวิธีที่เห็นได้ง่าย

## เกณฑ์การปฏิเสธรับสินค้า

คลังสินค้าจะปฏิเสธการรับสินค้าในกรณีต่อไปนี้:

1. ไม่มีใบนำเข้าคลัง หรือไม่ได้แจ้งล่วงหน้าก่อนสินค้าถึงคลัง
2. จัดส่งนอกเวลารับสินค้า (1 วันก่อนโปรโมชั่นใหญ่, 2 วันหลังโปรโมชั่นใหญ่, วันอาทิตย์, วันหยุดนักขัตฤกษ์)
3. ใบส่งสินค้าไม่ตรงกับจำนวนสินค้าจริง (คลังพิจารณาจากสินค้าที่ได้รับจริง)
4. บรรจุภัณฑ์ภายนอกหรือสินค้าภายในเสียหายชัดเจน
5. กล่องสินค้าไม่มีใบรายการสินค้าหรือรายละเอียด SKU ที่ชัดเจน

## มาตรฐานบรรจุภัณฑ์

หากต้องการบริการเพิ่มเติม เช่น ติดสติกเกอร์, จัดบรรจุภัณฑ์ใหม่ กรุณาติดต่อฝ่ายธุรกิจล่วงหน้าเพื่อขอราคา ค่าใช้จ่ายจะเรียกเก็บตามสัญญา
