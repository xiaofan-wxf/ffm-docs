# การสร้างโปรไฟล์ร้านค้าและการให้สิทธิ์

## การเพิ่มร้านค้า

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → คลิก **[ใหม่]**

1. กรอกชื่อร้านค้า
2. เลือกแพลตฟอร์มการขาย (TikTok / Shopee / Lazada / อื่นๆ)
3. เลือกประเทศ
4. กรอกคำอธิบายร้านค้า (ไม่บังคับ)
5. ข้อมูลผู้ส่ง: เลือก "ใช้ที่อยู่ผู้ส่งของคลังสินค้า"
6. คลิก **[บันทึก]** → คลิก **[เปิดใช้งาน]**

:::caution
ร้านค้าที่เพิ่มใหม่จะมีสถานะฉบับร่าง ต้องคลิก **[เปิดใช้งาน]** ก่อนใช้งาน หลังบันทึกแล้วให้ดำเนินการให้สิทธิ์แพลตฟอร์ม แล้วกลับมาตั้งค่าข้อมูล API ของร้านค้า
:::

---

## การให้สิทธิ์ร้านค้า

### การให้สิทธิ์ TikTok

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้า TikTok → คลิก **[ให้สิทธิ์]**

ร้านค้าข้ามพรมแดน 3PF และร้านค้าในประเทศของ TikTok ใช้ช่องทางการให้สิทธิ์ต่างกัน:

| ประเภทร้านค้า | ช่องทางการให้สิทธิ์ |
|-------------|------------------|
| ข้ามพรมแดน 3PF | เลือก "3P Seller" (เลือกช่องทางบัญชีย่อยของประเทศที่ต้องการ เช่น Thailand) |
| ร้านค้าในประเทศ | เลือก "Thailand" แล้วล็อกอินด้วยบัญชีและรหัสผ่าน |

:::caution ร้านค้าข้ามพรมแดน TK
สำหรับร้านค้าข้ามพรมแดน TikTok: หลังให้สิทธิ์บัญชีหลักแล้ว ต้องเลือกร้านค้าย่อยที่ต้องการให้สิทธิ์ เป็นการจับคู่แบบ 1 ต่อ 1
:::

#### การให้สิทธิ์หลายคลัง TikTok

สำหรับร้านค้า TikTok แบบหลายคลัง ต้องเลือก "เปิดใช้งานหลายคลัง" เมื่อสร้าง/แก้ไขโปรไฟล์ร้านค้าใน SCM:

1. ยืนยันว่าได้รับอนุมัติ Whitelist หลายคลังบนแพลตฟอร์ม TikTok แล้ว
2. โปรไฟล์ร้านค้า SCM → แก้ไข → เลือก ☑️ **เปิดใช้งานหลายคลัง**
3. ไม่สามารถยกเลิกการเลือกหลังบันทึกแล้ว — ดำเนินการให้สิทธิ์ต่อ

**วิธีระบุว่า TikTok เป็นหลายคลังหรือไม่:** เมื่อสร้างสินค้าระดับโลกบน TikTok ไปที่โมดูล [คลังสินค้าและสินค้าคงคลัง]:
- **หลายคลัง:** สามารถกำหนดสินค้าให้คลังต่างกันและกรอกสต็อกแยกตามคลัง
- **ปกติ (ไม่ใช่หลายคลัง):** เลือกได้เพียงคลังเดียวต่อประเทศ

### การให้สิทธิ์ Shopee

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้า Shopee → คลิก **[ให้สิทธิ์]**

| ประเภทร้านค้า | วิธีล็อกอิน |
|-------------|-----------|
| ร้านค้าในประเทศ | เลือกประเทศ แล้วกรอกบัญชีและรหัสผ่าน |
| ร้านค้าข้ามพรมแดน 3PF | คลิก "Switch to Sub Account" แล้วล็อกอินด้วยบัญชีหลัก |

---

### การให้สิทธิ์ Lazada

การให้สิทธิ์ Lazada มี 2 ขั้นตอน: **สมัครใช้ Flash WMS ในตลาดบริการ Lazada ก่อน แล้วจึงให้สิทธิ์ใน SCM**

#### ขั้นตอนที่ 1: ตลาดบริการ Lazada

1. ล็อกอิน Lazada Seller Center → คลิก **ตลาดบริการ**
2. ค้นหา `Flash` → หา **FLASH WMS**
3. เลือก **[ให้สิทธิ์เท่านั้น]** → ระยะเวลา: **6 เดือน** → คลิก **[ให้สิทธิ์]**
4. เลือก "ฉันยอมรับและลงนาม" → คลิก **[ยืนยัน]** → ข้อความ "สั่งซื้อสำเร็จ" ปรากฏ

#### ขั้นตอนที่ 2: การให้สิทธิ์ระบบ SCM

5. กลับ SCM → การตั้งค่า → โปรไฟล์ร้านค้า → เลือกร้านค้า → คลิก **[ให้สิทธิ์]**
6. เลือกประเทศ → กรอกอีเมลและรหัสผ่านร้านค้า → คลิก "Submit"
7. "Authorization success" ยืนยันว่าเชื่อมต่อสำเร็จ

หลังสำเร็จ สถานะการให้สิทธิ์ของร้านค้าใน SCM จะอัปเดตเป็น **ให้สิทธิ์แล้ว** พร้อมวันหมดอายุ

:::tip
การให้สิทธิ์ Lazada มีวันหมดอายุ ต้องต่ออายุก่อนหมดอายุ มิฉะนั้นคำสั่งซื้อจะหยุดซิงค์
:::

## การตั้งค่าหลังให้สิทธิ์

### 1. อัปเดตที่อยู่จัดส่งบนแพลตฟอร์ม

หลังให้สิทธิ์แล้ว ต้องอัปเดต **ที่อยู่จัดส่ง** ในระบบหลังบ้านของร้านค้าบนแพลตฟอร์มเป็นที่อยู่คลัง Flash:
- TikTok: โปรไฟล์ร้านค้า → การจัดการคลังสินค้า → เลือกคลัง Flash Fulfillment
- Lazada: Seller Center → โลจิสติกส์ → ที่อยู่จัดส่ง → กรอกที่อยู่คลัง Flash

### 2. การตั้งค่าคลังแพลตฟอร์มใน SCM

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้าที่ให้สิทธิ์แล้ว → คลิก **[แก้ไข]**

1. คลิก **[ดึงคลังแพลตฟอร์ม]** เพื่อดึงรายการคลังจากแพลตฟอร์ม
2. หาคลัง Flash → คลิก **[แก้ไข]** ทางขวา
3. ตั้ง "รับคำสั่งซื้อจากคลังนี้": **ใช่**
4. เลือกคลัง FFM ที่ตรงกัน → บันทึก

## การเปิดใช้งานการอนุมัติอัตโนมัติ

เมื่อเปิดใช้งานแล้ว คำสั่งซื้อที่เข้าสู่ SCM จะได้รับการอนุมัติและส่งไปยังคลังโดยอัตโนมัติโดยไม่ต้องตรวจสอบด้วยตนเอง

**เส้นทาง:** SCM → การตั้งค่า → การตั้งค่านโยบาย → การตั้งค่าการตรวจสอบคำสั่งซื้อ → คลิก **[แก้ไข]**

1. เลือก ☑️ **เปิดใช้งานการอนุมัติอัจฉริยะ**
2. คลิก **[บันทึก]**

:::info
ค่าเริ่มต้นจะใช้กับร้านค้าทั้งหมดและแหล่งที่มาคำสั่งซื้อทั้งหมด สามารถเปิดใช้งานเฉพาะร้านค้าที่ต้องการได้เช่นกัน
:::

## การตั้งค่าซิงค์สต็อกอัตโนมัติ

การซิงค์สต็อกต้องตั้งค่า Product Mapping ก่อน (ดู[คู่มือ Product Mapping](./product-mapping)) จึงเปิดใช้งานซิงค์อัตโนมัติได้

### แก้ไขจำนวนมากตามร้านค้า

**เส้นทาง:** สินค้า → Product Mapping → **[แก้ไขจำนวนมากตามร้านค้า]**

1. เลือกร้านค้าที่ต้องการเปิดใช้ซิงค์สต็อกอัตโนมัติ
2. ตั้ง "เปิดใช้อัปเดตสต็อก": **ใช่**
3. ตั้ง "เปอร์เซ็นต์อัปเดตสต็อก": ค่าเริ่มต้น **100%** (ซิงค์สต็อกคลังทั้งหมดไปยังแพลตฟอร์ม)
   - หากหลายร้านค้าใช้คลังเดียวกัน ให้กรอกเปอร์เซ็นต์ตามสัดส่วนที่ต้องการ
4. บันทึก — ระบบจะซิงค์ตามกำหนดเวลา

### แก้ไขข้อมูลสต็อกจำนวนมากตามสินค้า

**เส้นทาง:** สินค้า → Product Mapping → เลือกสินค้า → คลิก **[แก้ไขข้อมูลสต็อกจำนวนมาก]**

ตั้ง "เปิดใช้อัปเดตสต็อก: ใช่" และ "เปอร์เซ็นต์อัปเดตสต็อก" แล้วบันทึก
