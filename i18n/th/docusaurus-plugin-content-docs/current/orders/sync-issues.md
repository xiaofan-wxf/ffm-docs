# ปัญหาการดึงและซิงค์ออร์เดอร์

## ออร์เดอร์ไม่เข้า SCM

**สาเหตุ:** ออร์เดอร์บนแพลตฟอร์มถูกกดจัดส่งด้วยตนเอง ทำให้สถานะเปลี่ยนและ API ไม่สามารถ Push ได้

**วิธีแก้ไข (ซิงค์ด้วยตนเอง):**
1. SCM → ขาย → ใบสั่งจัดส่ง → คลิกลูกศรดรอปดาวน์ถัดจาก **[เพิ่มใหม่]** → เลือก **ร้านค้าออนไลน์**
2. กรอกเลขออร์เดอร์ภายนอก (เลขออร์เดอร์จากแพลตฟอร์ม) → คลิก **[ดึงออร์เดอร์]** และ **[ซิงค์ Log ออร์เดอร์]**
3. ออร์เดอร์จะปรากฏในหน้าใบสั่งจัดส่ง

**หมายเหตุออร์เดอร์ COD:** การ Push ออร์เดอร์ COD ล่าช้ากว่าออร์เดอร์ชำระเงินปกติ รอสักครู่เพื่อให้ระบบดึงอัตโนมัติ หรือใช้วิธีซิงค์ด้วยตนเองด้านบน

## Sync Log: ออร์เดอร์ไม่ได้อยู่ในคลังนี้

**Log เต็ม:** `Not configured to get orders from this warehouse: 748226486355xxxxxxxx`

**ขั้นตอนการแก้ไข:**
1. SCM → ตั้งค่า → โปรไฟล์ร้านค้า → ค้นหาร้านค้าที่ออร์เดอร์สังกัด → คลิก **[แก้ไข]**
2. คลิก **[ดึงคลังจากแพลตฟอร์ม]** → ตรวจสอบว่าคลัง Flash ปรากฏขึ้นหรือไม่
3. หากแสดงคลังอื่น ให้อัปเดตที่อยู่จัดส่งเป็นที่อยู่คลัง Flash ในแพลตฟอร์ม
4. คลิก **[ดึงคลังจากแพลตฟอร์ม]** อีกครั้ง → เมื่อคลัง Flash ปรากฏ คลิก **[แก้ไข]**
5. ตั้งค่า "ดึงออร์เดอร์จากคลังนี้": **ใช่** → บันทึก

## ข้อผิดพลาดในการประมวลผลออร์เดอร์ล่วงหน้า

### ข้อผิดพลาดสินค้า

**สาเหตุ:**
- ไม่ได้ระบุ Seller SKU ในลิสต์สินค้าบนแพลตฟอร์ม
- SKU บนแพลตฟอร์มไม่ตรงกับโปรไฟล์สินค้าใน SCM

**วิธีแก้ไข:** ทำ Mapping ด้วยตนเองใน SCM Product Mapping หรือแก้ไข SKU บนแพลตฟอร์มแล้วซิงค์ใหม่

### ข้อผิดพลาดที่อยู่

**สาเหตุ:** โปรไฟล์ร้านค้ามีการติ๊ก "เปิดใช้การจัดส่งด้วยตนเอง (ขนส่งออฟไลน์)" ทำให้ระบบตรวจสอบที่อยู่แพลตฟอร์มแล้วไม่พบในฐานข้อมูลที่อยู่ขนส่งออฟไลน์

**วิธีแก้ไข:**
1. โปรไฟล์ร้านค้า → คลิก **[แก้ไข]** → **ยกเลิกการติ๊ก** "เปิดใช้การจัดส่งด้วยตนเอง (ขนส่งออฟไลน์)"
2. การประมวลผลออร์เดอร์ล่วงหน้า → เลือกออร์เดอร์ที่มีข้อผิดพลาดที่อยู่ → คลิก **[ลบ]**
3. ใบสั่งจัดส่ง → ดรอปดาวน์ใหม่ → ซิงค์ออร์เดอร์ใหม่

## ตั้งค่า Product Mapping แล้วแต่ออร์เดอร์จับคู่กับสินค้าผิด

**สาเหตุ:** เมื่อออร์เดอร์เข้าระบบ ระบบจะพยายามจับคู่บาร์โค้ดสินค้าก่อน หากล้มเหลวจึงจับคู่ตาม Product Mapping หากมีบาร์โค้ดซ้ำในโปรไฟล์สินค้า อาจจับคู่ผิด

**วิธีแก้ไข:** ตรวจสอบบาร์โค้ดซ้ำในโปรไฟล์สินค้า SCM แก้ไขแล้วซิงค์ออร์เดอร์ใหม่
