# การสร้างใบแจ้งรับสินค้า

ใบแจ้งรับสินค้า (คำสั่ง AN) คือเอกสารที่ใช้รับสินค้าเข้าคลัง คลังสินค้าใช้เอกสารนี้ในการรับและจัดเก็บสินค้า

## ขั้นตอนพื้นฐาน

**เส้นทาง:** SCM → เอกสารสินค้าคงคลัง → ใบแจ้งรับสินค้า → คลิก **[ใหม่]**

### ขั้นตอนที่ 1: กรอกใบแจ้งรับสินค้า

1. เข้าหน้าสร้างใบแจ้งรับสินค้าใหม่
2. เลือกประเภทการรับสินค้า
3. คลิก **[เลือก]** ในส่วนข้อมูลสินค้าเพื่อเพิ่มรายการ
4. กรอกจำนวนสินค้าแต่ละรายการ
5. กรอกหมายเหตุในช่องบันทึก (เช่น หมายเลขพัสดุขาเข้า)
6. คลิก **[บันทึก]**

:::caution สำคัญ
ใบแจ้งรับสินค้าที่บันทึกใหม่จะมีสถานะ **รอตรวจสอบ** **เมื่ออนุมัติและส่งไปยังคลังแล้ว จะไม่สามารถสร้างข้อมูลรายการกล่องได้อีก** ต้องจัดการรายการกล่องให้เสร็จก่อนอนุมัติเสมอ
:::

### ขั้นตอนที่ 2: สร้างรายการกล่อง (ข้อมูลการบรรจุ)

รายการกล่องจะติดไว้ด้านนอกแต่ละกล่องเพื่อให้คลังระบุเจ้าของและข้อมูลใบแจ้งรับสินค้าเมื่อสินค้ามาถึง

**เส้นทาง:** เอกสารสินค้าคงคลัง → ใบแจ้งรับสินค้า → คลิกหมายเลข AN (สถานะ: ยังไม่อนุมัติ) → เข้าหน้ารายละเอียด → คลิก **[การจัดการรายการกล่อง]**

มีสองวิธีในการกรอกข้อมูลการบรรจุ:

#### วิธี A: แก้ไขโดยตรง (สินค้าน้อยรายการ)

คลิก **[แก้ไข]** → เพิ่มสินค้าและจำนวนต่อกล่อง → คลิก **[บันทึก]**

#### วิธี B: นำเข้าจำนวนมาก (หลาย SKU หรือหลายกล่อง)

1. คลิก **[นำเข้าจำนวนมาก]** → **[ดาวน์โหลดแม่แบบ]**
2. กรอกข้อมูลในแม่แบบ:

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| Quantity Per Box | จำนวนสินค้าต่อกล่อง |
| Number Of Boxes | จำนวนกล่องทั้งหมด |
| Barcode | บาร์โค้ดจริงของสินค้า |

3. บันทึกไฟล์แล้วคลิก **[เปิดไฟล์]** เพื่ออัปโหลด
4. เมื่อระบบแสดง "จำนวนที่นำเข้าได้: X รายการ" ให้คลิก **[นำเข้า]**
5. หลังนำเข้าเสร็จ คลิก **[ดาวน์โหลดรายการกล่อง]** เพื่อสร้าง PDF

### ขั้นตอนที่ 3: พิมพ์รายการกล่องและอนุมัติ

1. ดาวน์โหลด PDF รายการกล่องและพิมพ์
2. ติดฉลากด้านนอกแต่ละกล่องที่ตรงกัน
3. กลับไปที่รายการใบแจ้งรับสินค้า → เลือกคำสั่ง AN → คลิก **[อนุมัติ]** เพื่อส่งไปยังคลัง

**เนื้อหาในฉลากกล่อง:** สร้างอัตโนมัติ รวมถึง: ข้อมูลเจ้าของ หมายเลขใบแจ้งรับสินค้า หมายเลขกล่อง/จำนวนกล่องทั้งหมด บาร์โค้ดและจำนวนสินค้า

---

## กล่องผสม SKU

ใช้เมื่อหนึ่งกล่องมีหลาย SKU

**เส้นทาง:** เอกสารสินค้าคงคลัง → ใบแจ้งรับสินค้า → คลิกหมายเลข AN ที่ยังไม่อนุมัติ → คลิก **[แก้ไข]**

1. คลิก **[เพิ่มสินค้า]** และเลือกรายการ
2. คลิก **[กล่องผสม]** และกรอกจำนวนในกล่องผสม
3. กรอกจำนวนต่อกล่องและจำนวนกล่องในแต่ละแถว
4. คลิก **[บันทึก]**
5. คลิก **[ดาวน์โหลดรายการกล่อง]** เพื่อออก PDF กล่องผสม
6. พิมพ์และติดบนกล่องที่ตรงกัน

**ตัวอย่าง:**
- กล่อง 1/2: สินค้า A (5 ชิ้น/กล่อง) + สินค้า B (10 ชิ้น/กล่อง)
- กล่อง 2/2: สินค้า A (5 ชิ้น/กล่อง) + สินค้า B (10 ชิ้น/กล่อง)

:::info
สำหรับกล่องผสม SKU ทั้งหมดในกล่องเดียวกันจะพิมพ์บนฉลากเดียว เพื่อให้คลังตรวจนับได้ง่าย
:::
