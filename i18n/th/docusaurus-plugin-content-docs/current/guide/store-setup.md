# การสร้างโปรไฟล์ร้านค้าและการให้สิทธิ์

## เพิ่มร้านค้า

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → คลิก **[ใหม่]**

![รายการโปรไฟล์ร้านค้า คลิกใหม่](/img/11_店铺档案列表.jpg)

1. กรอกชื่อร้านค้า
2. เลือกแพลตฟอร์มการขาย (TikTok / Shopee / Lazada / อื่นๆ)
3. เลือกประเทศ
4. คลิก **[บันทึก]** → คลิก **[เปิดใช้งาน]**

![แบบฟอร์มเพิ่มร้านค้าใหม่](/img/11_新增店铺档案.jpg)

:::caution
ร้านค้าที่เพิ่มใหม่จะมีสถานะฉบับร่าง ต้องคลิก **[เปิดใช้งาน]** ก่อนใช้งาน หลังบันทึกแล้วให้ดำเนินการให้สิทธิ์แพลตฟอร์ม แล้วกลับมาตั้งค่าข้อมูล API ของร้านค้า
:::

## การอนุญาตร้านค้า

### TikTok

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้า TikTok → คลิก **[ให้สิทธิ์]**

ร้านค้าข้ามพรมแดน 3PF และร้านค้าในประเทศของ TikTok ใช้ช่องทางการให้สิทธิ์ต่างกัน:

| ประเภทร้านค้า | ช่องทางการให้สิทธิ์ |
|-------------|------------------|
| ข้ามพรมแดน 3PF | เลือก "Plus seller" |
| ร้านค้าในประเทศ | เลือก "Thailand" แล้วล็อกอินด้วยบัญชีและรหัสผ่าน |

![การเลือกช่องทางอนุญาต TikTok](/img/12_TikTok授权入口.jpg)

:::caution ร้านค้าข้ามพรมแดน TK
TK ข้ามพรมแดน: หลังให้สิทธิ์บัญชีหลักแล้ว ต้องเลือกร้านค้าย่อยที่ต้องการให้สิทธิ์ เป็นการจับคู่แบบ 1 ต่อ 1 หากต้องการใช้หลายคลัง ต้องเปิดใช้งานตั้งแต่ตอนสร้างโปรไฟล์ร้านค้า (ไม่สามารถยกเลิกหลังบันทึกแล้ว)
:::

![คำอธิบาย TikTok หนึ่งสินค้าหลายคลัง](/img/12_TikTok一品多仓说明.jpg)

### Shopee

**เส้นทาง:** SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้า Shopee → คลิก **[ให้สิทธิ์]**

| ประเภทร้านค้า | วิธีล็อกอิน |
|-------------|-----------|
| ร้านค้าในประเทศ | เลือกประเทศ แล้วกรอกบัญชีและรหัสผ่าน |
| ร้านค้าข้ามพรมแดน 3PF | คลิก "Switch to Sub Account" แล้วล็อกอินด้วยบัญชีหลัก |

![การอนุญาต Shopee ร้านค้าในประเทศ](/img/13_Shopee授权_本土店.jpg)

![การอนุญาต Shopee 3PF](/img/13_Shopee授权_3PF.jpg)

### Lazada

Lazada ต้องสมัครใช้ Flash WMS ในตลาดบริการก่อน แล้วจึงกลับมาให้สิทธิ์ใน SCM

:::caution
Lazada อัปเดตกระบวนการให้สิทธิ์แล้ว กรุณาทำตามขั้นตอนล่าสุด
:::

1. ล็อกอิน Lazada Seller Center → คลิก **[ตลาดบริการ]**

![การค้นหาตลาดบริการ Lazada](/img/14_Lazada服务市场搜索.jpg)

2. ค้นหา `Flash` → หา **Flash WMS** → คลิกแอป → เลือก **[อนุญาตเท่านั้น]** → ระยะเวลา **ครึ่งปี** → คลิก **[อนุญาตใช้งาน]**

![การเลือกวิธีอนุญาต Lazada](/img/14_Lazada选择授权方式.jpg)

3. เลือก "ฉันยอมรับและลงนาม" → คลิก **[ยืนยัน]** → ปรากฏข้อความ "สั่งซื้อสำเร็จ"

![การยืนยันการสั่งซื้อ Lazada](/img/15_Lazada确认订购.jpg)

![การสั่งซื้อ Lazada สำเร็จ](/img/15_Lazada订购成功.jpg)

4. ในหน้าสั่งซื้อสำเร็จ คลิกปุ่ม "อนุญาตบริการ"
5. กลับ SCM → การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้า Lazada → คลิก **[ให้สิทธิ์]**
6. ในหน้า Lazada Open Platform เลือกประเทศ → กรอกอีเมลและรหัสผ่าน → คลิก Submit

![การอนุญาต Lazada Open Platform](/img/16_Lazada_OpenPlatform授权.jpg)

![การอนุญาต Lazada สำเร็จ](/img/16_Lazada授权成功.jpg)

## เชื่อมต่อคลัง Flash

หลังให้สิทธิ์แล้ว ต้องผูกคลังแพลตฟอร์มกับคลัง Flash ใน SCM เพื่อให้ระบบดึงคำสั่งซื้อจากคลังนั้นได้ถูกต้อง

**เส้นทาง:** การตั้งค่า → โปรไฟล์ร้านค้า → หาร้านค้าที่ให้สิทธิ์แล้ว → คลิก **[แก้ไข]**

1. คลิก **[ดึงคลังแพลตฟอร์ม]** เพื่อดึงรายการคลังจากแพลตฟอร์ม
2. คลิก **[แก้ไข]** ทางขวาของคลัง Flash ในรายการ

![การตั้งค่าคลังแพลตฟอร์ม](/img/17_平台仓库设置.jpg)

3. ตั้ง "รับคำสั่งซื้อจากคลังนี้": **ใช่**
4. เลือกคลัง FFM ที่ตรงกัน
5. คลิก **[บันทึก]**

![การกำหนดค่าการผูกคลัง](/img/17_仓库绑定配置.jpg)

:::caution
หลังจากทำขั้นตอนนี้เสร็จ ระบบจึงจะดึงคำสั่งซื้อจากคลัง Flash ที่กำหนด หากคำสั่งซื้อไม่เข้า SCM ให้ตรวจสอบการตั้งค่านี้ก่อน
:::

## เปิดการอนุมัติออเดอร์อัตโนมัติ

เมื่อเปิดใช้งานแล้ว คำสั่งซื้อที่เข้าสู่ SCM จะได้รับการอนุมัติและส่งไปยังคลังโดยอัตโนมัติโดยไม่ต้องตรวจสอบด้วยตนเอง

**เส้นทาง:** SCM → การตั้งค่า → การตั้งค่านโยบาย → การตั้งค่าการตรวจสอบคำสั่งซื้อ → คลิก **[แก้ไข]**

1. เลือก ☑️ **เปิดใช้งานการอนุมัติอัจฉริยะ**
2. คลิก **[บันทึก]**

:::info
ค่าเริ่มต้นจะใช้กับร้านค้าทั้งหมดและแหล่งที่มาคำสั่งซื้อทั้งหมด สามารถเปิดใช้งานเฉพาะร้านค้าที่ต้องการได้เช่นกัน
:::

## การตั้งค่าซิงค์สินค้าคงคลังอัตโนมัติ

การซิงค์สต็อกต้องตั้งค่า Product Mapping ก่อน (ดู[คู่มือ Product Mapping](./product-mapping)) จึงเปิดใช้งานซิงค์อัตโนมัติได้

### แก้ไขจำนวนมากตามร้านค้า

**เส้นทาง:** สินค้า → Product Mapping → **[แก้ไขจำนวนมากตามร้านค้า]**

![รายการความสัมพันธ์การแมปสินค้า](/img/18_商品映射关系列表.jpg)

1. เลือกร้านค้าที่ต้องการเปิดใช้ซิงค์สต็อกอัตโนมัติ
2. ตั้ง "เปิดใช้อัปเดตสต็อก": **ใช่**
3. ตั้ง "เปอร์เซ็นต์อัปเดตสต็อก": ค่าเริ่มต้น **100%** (ซิงค์สต็อกคลังทั้งหมดไปยังแพลตฟอร์ม)
   - หากหลายร้านค้าใช้คลังเดียวกัน ให้กรอกเปอร์เซ็นต์ตามสัดส่วนที่ต้องการ
4. บันทึก — ระบบจะซิงค์ตามกำหนดเวลา

![แก้ไขจำนวนมากตามร้านค้า](/img/18_按店铺批量修改.jpg)

### แก้ไขข้อมูลสต็อกจำนวนมากตามสินค้า

**เส้นทาง:** สินค้า → Product Mapping → เลือกสินค้า → คลิก **[แก้ไขข้อมูลสต็อกจำนวนมาก]**

![เลือกสินค้าเพื่อแก้ไขจำนวนมาก](/img/19_勾选商品批量修改.jpg)

ตั้ง "เปิดใช้อัปเดตสต็อก: ใช่" และ "เปอร์เซ็นต์อัปเดตสต็อก" แล้วบันทึก

![แก้ไขข้อมูลสต็อกจำนวนมาก](/img/19_批量修改库存信息.jpg)
