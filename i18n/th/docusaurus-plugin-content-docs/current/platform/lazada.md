# การเชื่อมต่อร้านค้า Lazada

## ขั้นตอนการเชื่อมต่อ

1. เข้าสู่ระบบ Lazada Seller Center → คลิก **Marketplace**

![ช่องทาง Marketplace](/img/img_006.png)

2. ค้นหา `Flash` → ค้นหาแอป **FLASH WMS**

![ค้นหา Flash WMS](/img/img_007.png)
![แอป Flash WMS](/img/img_008.png)

3. เลือก **[Authorize Only]** → เลือกระยะเวลา **6 เดือน** → คลิก **[Authorize]**

![เลือก Authorize Only](/img/img_009.png)

4. ติ๊กถูก "ยอมรับและลงนาม" → คลิก **[ยืนยัน]** → ระบบแจ้ง "สั่งซื้อสำเร็จ"

![ติ๊กถูกยอมรับ](/img/img_011.png)

5. กลับไปที่ SCM → ตั้งค่า → โปรไฟล์ร้านค้า → เลือกร้านค้าที่ต้องการ → คลิก **[เชื่อมต่อ]**

![เชื่อมต่อโปรไฟล์ร้านค้า SCM](/img/img_012.png)

6. เลือกประเทศ → กรอกอีเมลและรหัสผ่านของร้านค้า → คลิก "Submit"

![เชื่อมต่อสำเร็จ](/img/img_013.png)

## การตั้งค่าหลังเชื่อมต่อ

หลังเชื่อมต่อสำเร็จ ต้องอัปเดต**ที่อยู่จัดส่ง**ในแพลตฟอร์มให้เป็นที่อยู่คลัง Flash

![ตัวอย่างการตั้งค่าที่อยู่คลัง](/img/img_014.png)

โปรไฟล์ร้านค้าใน SCM → คลิก **[แก้ไข]** → การตั้งค่าคลังแพลตฟอร์ม:
- คลิก **[ดึงคลังจากแพลตฟอร์ม]**
- คลิก **[แก้ไข]** ด้านขวา → เลือกคลัง Flash
- ดึงออร์เดอร์จากคลังนี้: **ใช่**
- ติ๊กคลัง FFM ที่ต้องการ → บันทึก

## ปัญหาที่พบบ่อย

### พัสดุ DOF ไม่สามารถรับพัสดุได้

**สาเหตุ:** ร้านค้า Lazada ใหม่ที่มีออร์เดอร์เฉลี่ยน้อยกว่า 10 ออร์เดอร์ต่อวัน แพลตฟอร์มกำหนดให้ผู้ค้าส่งพัสดุไปที่จุดรับพัสดุด้วยตนเอง

**การขอเปิด Pickup:** กรุณาติดต่อฝ่ายธุรกิจเพื่อยื่นคำร้อง

**วิธีแก้ไขชั่วคราวก่อนเปิด Pickup:** นำพัสดุส่งที่จุดรับพัสดุของขนส่ง สามารถใช้บัญชีสำรองจ่ายค่าตอบแทนพนักงาน และบันทึกค่าใช้จ่ายในบิลรายเดือน

![การขอเปิด Pickup](/img/img_063.png)

### การเชื่อมต่อคลังตรวจสอบคุณภาพ Lazada

หากต้องการเชื่อมต่อคลังตรวจสอบคุณภาพ Lazada กรุณาติดต่อผู้จัดการโครงการเพื่อรับเอกสารขั้นตอนโดยเฉพาะ
