# การยกเลิกออร์เดอร์จากแพลตฟอร์ม

## การยกเลิกในโหมด SCM Pull

| เวลาที่ยกเลิก | วิธีจัดการ |
|--------------|----------|
| ยกเลิก**ก่อน**อนุมัติ SCM (สถานะแพลตฟอร์ม: ยกเลิกแล้ว) | ไม่ต้องอนุมัติ ไม่ต้องดำเนินการเพิ่มเติม |
| ยกเลิก**หลัง**อนุมัติ SCM เข้า WMS แล้ว (สถานะแพลตฟอร์ม: ยกเลิกแล้ว) | แจ้งลูกค้า คลังดำเนินการสกัดกั้นและเรียกคืนพัสดุ |

## การยกเลิกในโหมด ERP Push

| สถานการณ์ | วิธีจัดการ |
|----------|----------|
| ยกเลิกหลัง ERP Push เข้า SCM แล้ว (สถานะแพลตฟอร์มไม่ทราบ) | สถานะแสดง "ดึงใบปะหน้าล้มเหลว" แจ้งลูกค้าให้สกัดกั้น |
| ยกเลิกหลัง ERP Push และอนุมัติเข้า WMS แล้ว | แจ้งข้อผิดพลาดที่จุดส่งมอบขนส่ง แจ้งลูกค้าให้สกัดกั้น |

![การจัดการยกเลิก ERP Push](/img/img_062.png)

**การสกัดกั้น:** ค้นหาใบสั่งจัดส่งใน SCM WMS → คลิก **[สกัดกั้น]** คลังจะดำเนินการเรียกคืนพัสดุ
