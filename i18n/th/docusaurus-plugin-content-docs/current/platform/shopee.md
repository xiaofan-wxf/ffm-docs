# การเชื่อมต่อร้านค้า Shopee

## ช่องทางการเชื่อมต่อ

SCM → ตั้งค่า → โปรไฟล์ร้านค้า → เลือกร้านค้า Shopee → คลิก **[เชื่อมต่อ]**

## ปัญหาที่พบบ่อย

### การเชื่อมต่อใหม่ล้มเหลวหลังจากการเชื่อมต่อเดิมหมดอายุ

**วิธีแก้ไข:**
1. ยกเลิกการเชื่อมต่อเดิมใน Shopee Seller Center
2. กลับไปที่โปรไฟล์ร้านค้าใน SCM และคลิก **[เชื่อมต่อ]** อีกครั้ง
3. ทำตามขั้นตอน OAuth ที่ปรากฏขึ้น

### การเชื่อมต่อร้านค้า Shopee SIP International ล้มเหลว

**สาเหตุ:** โหมด SIP เป็นโครงสร้าง 1 ร้านหลักต่อหลายร้านย่อย ระบบยังไม่รองรับการเชื่อมต่อร้านย่อยแยกเดี่ยว

**วิธีแก้ไข:** ใช้วิธีกรอกออร์เดอร์ด้วยตนเอง ดาวน์โหลด PDF ใบปะหน้าพัสดุจากแพลตฟอร์มและอัปโหลด ระบบจะรู้จักเลขติดตามพัสดุและดำเนินการจัดส่งต่อได้

### การซิงค์สต็อกอัตโนมัติล้มเหลว

**Log: Failed to update stock**

ในโหมด Multi-warehouse แพลตฟอร์มไม่รองรับการอัปเดตสต็อกคลังต่างประเทศแยกเดี่ยว ให้อัปเดตสต็อกบนแพลตฟอร์มด้วยตนเองไปก่อนและรอการอัปเดต API จากแพลตฟอร์ม

**Log: Stock should be larger than 80**

ร้านค้าเข้าร่วมแคมเปญล็อคสต็อกของแพลตฟอร์ม สต็อกต้องมากกว่า 80 ชิ้นจึงจะอัปเดตได้

![แคมเปญล็อคสต็อก](/img/img_052.png)

### แพลตฟอร์มแยกออร์เดอร์ (ออร์เดอร์เข้า SCM แล้วแพลตฟอร์มแยก)

หากออร์เดอร์เข้า SCM แล้วและแพลตฟอร์มทำการแยกออร์เดอร์ กรุณาติดต่อเจ้าหน้าที่ปฏิบัติการเพื่อจัดการออร์เดอร์ย่อยด้วยตนเอง
